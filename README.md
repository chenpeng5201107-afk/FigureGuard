# FigureGuard｜科研图表急救室

面向大学生科研与实验场景的数据与图表质检 Web 应用，参赛作品（2026 Qoder 高校创造力大赛 · StudyHack 赛道）。

当前是 **Day 6 版本**，在「CSV 读取与预览」与**数据质量诊断**（缺失值统计 + 疑似重复记录检测 + 字段类型识别 + 类型冲突候选提示 + 分析准入判断，全部只读、按真实单元格计算）之上，把**图表实验室（F4 V2）**补齐为可交代口径的一版：柱状图 / 散点图 / 折线图，柱状图可逐条原始记录或按类别计算平均值 / 求和，图表标题、坐标轴标题与单位可自定义，并如实标注参与绘图与按缺失 / 类型 / 日期精度排除的记录数。异常值分析、图表表达诊断、修复对比、报告导出尚未开发。

## 现在能做什么

- 选择或拖拽本地 `.csv` 文件，在浏览器本地解析（整块上传区域都接受拖拽，也可以直接点击区域选择文件）
- 点击「体验示例数据」加载内置合成数据集 `public/examples/plant-growth.csv`，解析成功后自动定位到预览区
- 显示真实解析结果：记录数、字段数、数据体积、来源与实际使用的分隔符
- 显示解析发现的格式问题，区分「需要处理」与「说明性提示」，并定位到文件的**物理行号**（引号内的换行也占行）
- 常见边界情况已覆盖：UTF-8 BOM、CRLF 与混用换行符、引号内的逗号与换行、重复表头（按 Papa Parse 的重命名结果读取）、空表头、行长与表头不一致、只有表头、单列 CSV、非 UTF-8/二进制内容
- 空文件、非 `.csv`、超过 5 MB、编码不支持、缺少表头、读取失败都会给出明确的错误提示与建议做法
- 超过 50 行时先显示前 50 行，可按每批 50 行逐批加载（不会一次渲染数万行）
- 空单元格显示为「空值」标签，缺列显示为「—」，两者含义不同且有图例说明
- 预览区给出「数据质量概览」：数据总行数、存在空值的字段数、缺失单元格数量、疑似重复记录数量，数字全部来自逐格统计
- 缺失口径分开：空字符串算缺失、只有空白字符标为「疑似空白值」、`null` 是结构性缺列、`'0'` 与实际文本都不算缺失
- 完全重复记录（整行每个字段都相同）以「疑似重复记录，请人工确认」呈现，并给出重复组数 / 涉及记录数 / 额外副本数与数据行序号；不删除、不改写任何行
- 字段类型识别：每列自动推断为数值、日期、文本或类别、无法确定；标识符字段（如 sample_id、学号）与前导零编码（如 007）按文本处理，不被误判为数值
- 类型冲突候选：当一列具有稳定的主要类型时，标出与该类型不一致的单元格，支持点击定位到表格对应列与行；只报告、不修改、不删除、不填充任何单元格
- 数据不可信时（结构降级或存在解析错误）**不输出正式质量结论**，改为说明原因与怎么修；原始表格与解析告警照常可浏览
- 数值列右对齐并使用等宽数字，日期与文本列左对齐（只影响排版，单元格文字保持源文件原样）
- 结果对读屏可发现：失败面板是 `role="alert"`，成功结果有常驻的 `aria-live` 播报；系统开启「减少动态效果」时不做平滑滚动
- 图表实验室（Apache ECharts）：选图表类型与 X/Y 字段即可绘制真实图表；柱状图 X 取文本/类别、Y 取数值，散点图 X、Y 都取数值且必须是两个不同字段，折线图 X 取日期、Y 取数值
- 标题、坐标轴标题与单位都能自己填：默认标题由「图表类型 + 字段名 + 口径」生成，手填过的标题在换类型 / 换字段 / 换文件时不会被无提示覆盖；**单位只作为标注，不做任何换算**，留空时明确写「未填写单位」
- 柱状图默认**逐条原始记录**（一条记录一根柱子），可切换「按类别计算平均值」（给出每组有效样本数 `n`、原始数据行号与计算依据）或「按类别求和」（附可加性提醒）；聚合只生成新结果对象，不删除、不修改、不合并原始记录，也不生成误差棒、标准差与显著性标记
- 折线图按 UTC 解释日期、不依赖 `Date.parse()` 也不读浏览器时区：只接受能定位到具体日期的写法，`2026-01` 报告为「精度不足」而不补成某月第一天，`2026-02-30` 这类日历无效值计入排除；升序排列、同一时刻保留上传顺序、同日多条全部画出，不插值、不平滑、不预测、不默认平均或去重
- 类别重复时以数据行号区分，不会被错误合并；保留 `0`、负数与 `88.6` / `-4.2` 这类极端值（不擅自删除或裁剪）；小数位数只在展示文本上缩略，参与计算的值不变
- 图表统计基于**整份数据集**、不受表格 50 行分页影响；数值单元格复用既有数值形态判断再要求有限值，`1e999` / `abc` / `12.4 kg` 不算有效测量；标识符列不自动转数值
- 如实标注「原始记录 / 有效 / 缺失排除 / 类型排除 / 实际展示」五类数量，口径互斥、每条只计一次；单图有展示上限（柱状 100、散点 2000、折线 2000，聚合模式按类别组计），触顶时明确区分「有效但未显示」与「无效被排除」
- 字段类型不足以绘图（如散点只有一个数值字段、折线没有日期字段）、全部记录被排除、或数据不可信（结构降级 / 解析错误）时给出中文说明而不伪造图表；配置文本先清洗限长再展示，字段原值进入 tooltip 前统一转义防注入

## 技术栈

React 19 · TypeScript 7 · Vite 8 · Tailwind CSS 4 · Papa Parse 5 · Vitest 5 · Apache ECharts 5.6

纯前端架构，不使用数据库、登录和外部 API，用户数据不会离开浏览器。Apache ECharts 5.6 已按需引入（`echarts/core` + Bar/Line/Scatter + Grid/Tooltip + CanvasRenderer），只用官方模块化 API，不叠加 React 图表封装库。

## 快速开始

```bash
npm install          # 安装依赖
npm run dev          # 本地开发，默认 http://localhost:5173
npm run build        # 类型检查 + 生产构建，输出到 dist/
npm run preview      # 预览生产构建
npm test             # 运行 Vitest 单元与组件测试（解析跑 node 环境，组件测试用 jsdom）
npm run lint         # 运行 oxlint
```

要求 Node.js 20 或更高版本。

## 关于示例数据

`public/examples/plant-growth.csv` 是**合成的植物生长实验记录**，与任何真实实验无关。12 条记录中刻意保留了两处空值和两处可疑数值（如 88.6 cm、-4.2 cm），用于质检与图表功能的演示。当前版本会逐格统计出那 2 个空单元格并列出「height_cm 有 2 处内容不完整」；图表实验室三种画法都以这 12 条为输入：逐条柱状图绘制 10 个有效数值并声明未做聚合，按类别平均值给出 control `13.14`（n=5）与 treated `26.44`（n=5）及其计算依据，折线图按日期绘制这 10 条观测并说明 2 条缺失未参与。三种画法都保留 88.6 与 -4.2，**不会**判断它们是否离谱——异常值判定属于后续功能，页面上也没有对应入口。
